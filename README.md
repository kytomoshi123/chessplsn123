# ChessPlan — анализ партии и подсказки
Статический сайт: открой index.html или выложи папку на GitHub Pages / Netlify. Сервер и сборка не нужны.

Как пользоваться: введи ходы обеих сторон из своей партии (кликом по фигуре и клетке) или вставь PGN/FEN. Зелёная стрелка — лучший ход для тебя, красная — вероятный ход соперника. Кнопка «Анализ всей партии» классифицирует каждый ход обеих сторон.

Файлы: engine.js (правила, поиск, классификация жертв), openings.js (дебютная книга и ловушки), app.js (интерфейс), style.css, assets/icons.png (спрайт иконок классификации).

- Уровни «Рейтинг партии» настраиваются в массиве LV в engine.js: глубина, время расчёта, точность.
- Дебюты добавляй в openings.js: `Название|сложность 0–3|ходы в uci (e2e4 e7e5 ...)`.
- Иконки: если сдвинуты, поправь значения r и c в CLS (app.js) — это позиция в спрайте.
- Для настоящей силы подключи Stockfish.js вместо Eng.analyze.
