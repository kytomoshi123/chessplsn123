# ChessPlan
Режим: ты вводишь ходы обеих сторон из своей партии, сайт показывает лучший ход для тебя. Статический сайт: открой index.html или выложи папку на GitHub Pages / Netlify / любой хостинг. Сборки и серверов не нужно.

Файлы: engine.js (правила + поиск), openings.js (книга дебютов), app.js (интерфейс), style.css.

- Уровни (100–300 … 1900+) настраиваются в массиве LV в engine.js: глубина, шум, шанс ошибки, глубина теории.
- Дебюты добавляй в openings.js: `Название|сложность 0–3|ходы в формате e2e4`.
- Для настоящей силы: подключи Stockfish.js (WASM) и вызывай его вместо Eng.analyze на уровне 1900+.
